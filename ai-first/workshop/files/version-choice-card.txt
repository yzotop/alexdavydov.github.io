# Какую версию оставить рабочей?

В средней колонке запишите своё решение. Справа — учебный пример со сводкой недостач.

| Вопрос владельцу отчёта | Мой отчёт | Как я заполнил бы карточку |
|---|---|---|
| Кто пользуется сводкой и что решает? | По сводке … решает, … | Руководитель розницы выбирает, с кем из директоров разбирать недостачу. Для звонка нужно знать, к какому магазину относится строка. |
| На чём сравнили версии? | Снимок и справочник … Текущая версия … Кандидат … Ссылка на строки … | Обе версии получили одни и те же строки недостач и один справочник магазинов. Сверяю выбранный магазин по исходной записи. Если запись допускает два варианта, правильное действие — запросить уточнение. |
| Где кандидат помогает? | Строка … Раньше приходилось … Теперь можно … Основание … | Когда сокращённое название указывает только на один магазин, кандидат может сразу подставить его в сводку. Руководителю не приходится ждать ручной расшифровки названия. |
| Какая новая ошибка меняет действие? | Строка … Текущая версия … Кандидат … Из-за этого получатель может … | В строке «Центральный» подходят два магазина. Текущая версия просит ручную сверку. Кандидат приписывает недостачу одному магазину, и руководитель может вызвать на разговор чужого директора. |
| Какую версию оставляем и когда пересмотрим выбор? Если версия допущена с ограничением, какой результат проверки позволит владельцу его снять? | Оставляю …, потому что … К решению вернётся …, когда … Для снятия ограничения проверяем … | Оставляю текущую версию. Аналитик повторит сравнение на том же снимке после исправления. Я как владелец вернусь к выбору после проверки двух случаев. Для «Центрального» без уточняющих данных исправленная версия должна запросить сверку, а по однозначному сокращению — выбрать верный магазин. |
