Кто оплатил подписку после смены экрана?

Вопрос перед встречей

Сценарий AI-мастерской

Вариант C поднимает долю оплат после пробного периода. Есть ли основание предпочесть C, если хотим больше платящих пользователей среди всех участников?
Данные, которые получили оба агента

B — базовый экран Apple, в C добавили выбор Apple или веб со скидкой. Срез чуть позже трёх недель. Столбцы: метрика, события B, знаменатель B, события C, знаменатель C.

Старт пробного периода или подписки / участники
B — 844 / 3127
C — 749 / 3191
Платящие / участники
B — 198 / 3127
C — 187 / 3191
Оплатили после пробного периода / завершившие пробный период
B — 134 / 537
C — 139 / 493

Независимый ответ 1

На текущем срезе оснований предпочесть C нет. Среди всех участников оплатили 5,86% в C против 6,33% в B. Разница C минус B равна −0,47 процентного пункта, приблизительный 95%-й ДИ от −1,65 до +0,71. Пробный период или подписку в C начинали реже (23,47% против 26,99%). Рост с 24,95% до 28,19% среди завершивших пробный период описывает лишь часть участников. Для решения стоит дождаться одинакового срока наблюдения за оплатами всех участников.

Независимый ответ 2

Основания предпочесть C по этой цели нет. К моменту среза доля платящих среди всех участников составила 6,33% в B (198/3 127) и 5,86% в C (187/3 191), то есть в C примерно на 4,7 платящего меньше на тысячу. Рост с 24,95% до 28,19% касается только завершивших пробный период. Наблюдаемая разница по всем участникам ещё не доказывает преимущество B.

Критерий проверки

Считать 198/3127 и 187/3191. Рост 139/493 относительно 134/537 внутри завершивших не подтверждает преимущество C по платящим среди всех. Не заявлять доказанный вред.
