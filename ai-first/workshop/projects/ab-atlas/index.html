Источники и расчёты

Одна карточка соответствует одному эксперименту. По счётчикам в каждой группе можно пересчитать доли и их разницу. Когда авторы приводят только округлённые доли, разница приблизительна. Для результата из публикации команды в карточке приведены её формулировка и источник.

Для карточек Upworthy использованы данные Matias, Munger, Le Quéré и Ebersole, для ASOS — ASOS Digital Experiments Dataset, Liu и соавторы. Данные этих архивов доступны по лицензии CC BY 4.0. Для атласа отобраны эксперименты, размечены задачи и изменения, рассчитаны сравнения.
