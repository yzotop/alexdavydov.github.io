Изменить письмо о сроке подачи отчётности

Эксперимент реальный. Вопросы команды и пороги решения смоделированы.

Исходные данные

481 888 компаний получили одну из четырёх версий письма. В трёх новых версиях упростили инструкции и добавили призыв подать отчёт онлайн. Различались сообщение о поведении других компаний, сообщение о его динамике и рекомендация директора.

Подача онлайн
У новых писем авторы не выявили роста онлайн-подачи.
Просрочка подачи
Для писем A и C авторы сообщают о снижении вероятности просрочки на 2,4%.

Вопрос перед встречей

Вот результаты теста. Что скажешь перед встречей?

Первый ответ агента

Если цель — перевести компании на онлайн-подачу, команда не обнаружила роста ни у одной из трёх новых версий. Отдельный результат касается сроков: по оценке авторов, для писем A и C вероятность просрочки снизилась на 2,4%. Перед выбором письма я бы попросил долю просрочек по каждой группе, уточнил, имеются в виду проценты или процентные пункты, и посмотрел интервалы с учётом нескольких сравнений. По этой сводке выбрать между A и C или приписать результат конкретной фразе нельзя.

Уточнение команды

На встрече решаем только задачу онлайн-подачи отчётности. Какую версию письма выбрать по результату?

Второй ответ агента

Для цели онлайн-подачи я бы сохранил стандартное письмо. Ни одна новая версия не показала подтверждённого роста по этой метрике.

Редакторская проверка

В первом ответе агент развёл онлайн-подачу и просрочки. После уточнения выбрал исходное письмо для задачи онлайн-подачи: преимущество новых версий по этой цели не установлено.
