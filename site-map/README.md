# Прежняя карта сайта

С 25 октября 2026 `/site-map/` ведёт на общий каталог `/materials/`.
Страница графа, данные и прежний генератор сохранены в
`~/projects/_archive/davydov-my/site-structure-before-20261025-172434/`;
контрольные суммы — в его `manifest.json`.

`update_site_map.sh` останавливается до записи, чтобы случайный старый запуск
не вернул архивные данные. Каталог собирает `scripts/render_materials.py`
из статей и кейсов. Порядок добавления материалов —
[`docs/site-content-guide.md`](../docs/site-content-guide.md).
